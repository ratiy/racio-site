**H2:** Логіка START / SMART / FULL — _одна для всіх послуг_

**START** — мінімум для закриття законодавчої вимоги. Базовий пакет документів, онлайн-консультація, супровід планових перевірок. Підходить для малого бізнесу 10-30 осіб, де ОП — не пріоритет, але треба «щоб не штрафували».

**SMART** — оптимум для середнього бізнесу 30-100 осіб. Усе з START + виїзди інженера, квартальний аудит, компенсація штрафу до 50 тис. ₴, суміжні послуги (пожежна безпека включена). **80% клієнтів обирають SMART** — співвідношення ціна/обсяг найкраще.

FULL — enterprise-рівень для компаній 100+ осіб або з високими регуляторними вимогами (фарма, виробництво, критична інфраструктура). Виділений інженер, ISO-рівень організації, [цивільний захист](tsyvilnyi-zakhyst.html) і [оцінка ризиків](otsinka-ryzykiv.html) у пакеті, представництво в держорганах.

Тарифи фіксовані на рік — без індексації, без погодинних чеків, без «раптових доплат за нестандартні ситуації». Усі можливі додаткові витрати (нічні виїзди, судове представництво, розслідування НВ разовою послугою) прописані в договорі **наперед** фіксованими сумами.

#### Секція 9/10 · bg: `cream`

### Блок · FAQ
**Eyebrow:** FAQ
**H2:** Часті _запитання_ щодо тарифів

**Q1.** Чому SMART — anchor (рекомендуємо)?
**A:** 80% клієнтів 30-100 осіб обирають саме SMART. Це оптимальний баланс: включена пожежна безпека (economía ~13 тис. ₴/міс vs роздільно), виїзди інженера, квартальний аудит, компенсація штрафу до 50 тис. ₴. У STARTі немає виїздів, у FULL — надмірний для середнього бізнесу.

**Q2.** Чи можна знизити або підвищити тариф під час договору?
**A:** Так, у будь-який момент. Зміна з наступного календарного місяця. Без штрафу за downgrade. Upgrade — ефект одразу (доплачується різниця за поточний місяць пропорційно).

**Q3.** Чи включено ПДВ у ціни?
**A:** Ціни вказані без ПДВ. Для ФОП — працюємо без ПДВ (3% єдиного податку). Для ТОВ з ПДВ — +20% до вказаних цін.

**Q4.** Що таке SLA і як він фіксується?
**A:** SLA — гарантований час відповіді та реакції. Прописаний окремим пунктом у договорі з конкретними годинами й компенсаціями. У START — 1 робочий день, SMART — 4 години, FULL — 1 година цілодобово.

**Q5.** Що не входить у тарифи (коротко)?
**A:** Разове [розслідування НВ](rozsliduvannia-nv.html) (від 15 тис.), судове представництво (від 25 тис.), нічні виклики (+50%), декларація ПНО (45-150 тис.). Детальніше — блок «Що не входить» вище.

**Q6.** Чи можна договір на 3 роки з фіксацією ціни?
**A:** Так, для клієнтів FULL або комплексного ENTERPRISE-пакета. Знижка 8% на другий рік, 12% на третій. Детальні умови — у вашому договорі.

**Q7.** Як розраховується «кількість осіб» для тарифу?
**A:** Бере до уваги всіх працівників за трудовими договорами + цивільно-правовими договорами з регулярним виконанням робіт. ФОПи-підрядники (дизайн, маркетинг) — не рахуємо, якщо не присутні на об'єкті.

**Q8.** Чи можна оплатити чеком або криптовалютою?
**A:** Стандартно — банківський переказ на рахунок ТОВ. Для міжнародних клієнтів — SWIFT/SEPA, USDT/USDC (tax-compliant). Готівка — ні.
