#### Секція 14/18

### Блок · FAQ
**Eyebrow:** FAQ
**H2:** Часті _запитання_

**Q1.** Чим аутсорсинг ОП відрізняється від штатного інженера?
**A:** Штатний — одна людина з однією головою, за 2-3 роки вигорає або йде. Аутсорсинг — команда з 3-5 профільних інженерів, без залежності від однієї людини. Детальне порівняння по цифрах — на [сторінці аутсорсингу](autsorsynh.html).

**Q2.** Скільки коштує супровід охорони праці?
**A:** Від 8 000 ₴/міс за пакетом START до 20 000 ₴/міс за FULL. Точна вилка залежить від розміру компанії й галузі — [детальні тарифи](tarify.html) або в калькуляторі нижче.

**Q3.** Чи можемо ми обійтись без декларації ДСНС?
**A:** Якщо ви експлуатуєте об'єкт з прийомом клієнтів (ресторан, готель, офіс 500+ м², магазин понад 100 м²) — декларація обов'язкова. Без неї — штраф 17-51 тис. ₴ + припис про заборону діяльності. Детально — [на сторінці декларації ДСНС](deklaratsiia-dsns.html).

**Q4.** Ви проводите офіційне навчання НАПБ з посвідченням?
**A:** Ні, офіційне посвідчення НАПБ видає акредитований навчальний центр. Ми проводимо корпоративні практичні [тренінги з ОП](treningy-z-ohorony-pratsi.html) і [з ПБ](treningy-z-pojejnoi-bezpeky.html) — це різні продукти. Для посвідчення рекомендуємо партнерський центр.

**Q5.** Атестація робочих місць скасована — що робити з оцінкою ризиків?
**A:** З 1 січня 2023 атестація скасована. Замість неї — [оцінка ризиків на робочих місцях](otsinka-ryzykiv.html) за ISO 45001. Обов'язкова для всіх роботодавців із ≥1 працівником.

**Q6.** Що робити, якщо отримали припис Держпраці?
**A:** Викликати нас негайно — не давайте усних пояснень без юриста. Детальний [супровід перевірок Держпраці](suprovid-derzhpratsi.html) включає підготовку, присутність на перевірці й оскарження через суд (80% виграних справ).
