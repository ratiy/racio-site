Як побудовані тарифи

Логіка START / SMART / FULL — одна для всіх послуг

START — мінімум для закриття законодавчої вимоги. Базовий пакет документів, онлайн-консультація, супровід планових перевірок. Підходить для малого бізнесу 10-30 осіб, де ОП — не пріоритет, але треба «щоб не штрафували».

SMART — оптимум для середнього бізнесу 30-100 осіб. Усе з START + виїзди інженера, квартальний аудит, компенсація штрафу до 50 тис. ₴, суміжні послуги (пожежна безпека включена). 80% клієнтів обирають SMART — співвідношення ціна/обсяг найкраще.

FULL — enterprise-рівень для компаній 100+ осіб або з високими регуляторними вимогами (фарма, виробництво, критична інфраструктура). Виділений інженер, ISO-рівень організації, цивільний захист і оцінка ризиків у пакеті, представництво в держорганах.

Тарифи фіксовані на рік — без індексації, без погодинних чеків, без «раптових доплат за нестандартні ситуації». Усі можливі додаткові витрати (нічні виїзди, судове представництво, розслідування НВ разовою послугою) прописані в договорі наперед фіксованими сумами.

Галузеві надбавки

Чи залежить ціна від галузі?

Ключова надбавка — немає. Тарифи START/SMART/FULL однакові для всіх галузей. Спеціалізація нашої команди під вашу вертикаль — внутрішня організація RACIO, не окрема платна опція.

Що реально впливає на ціну:

  • → Розмір і кількість об'єктів. Для мережі 10+ локацій — знижка 15%, 20+ — 20%.
  • → Наявність небезпечних процесів. ЛЗР, хімія, вибухонебезпечні зони — потребують додаткової документації (ПЛАС, декларація ПНО) — це окремі разові послуги, не надбавка до супроводу.
  • → Формат роботи. Для дистанційних команд (IT без офісу) тариф знижений — немає виїздів і огляду приміщень.
  • → Корпоративний EHS. Для клієнтів з HQ-стандартами (GDP, ISO 45001) — додається тільки вартість оцінки ризиків під ISO + доплата за координацію з HQ (10-15% до FULL).

Окремі платні послуги

Для прозорості — нижче послуги, які виконуємо, але вони НЕ включені у стандартні тарифи START/SMART/FULL. Замовляються разово або за фактом виклику.

  • → Розслідування НВ з виїздом — від 15 000 ₴. Окремо, бо вимагає 24/7-реакції й команди з юриста + інженера. Деталі на сторінці розслідування НВ.
  • → Судове представництво — від 25 000 ₴ за інстанцію + судовий збір. При виграві — компенсується Держпраці або ДСНС. Супровід перевірок включає базовий юридичний супровід, судовий — окремо.
  • → Нічний / аварійний виклик (22:00-08:00) — +50% до годинного тарифу інженера. У SMART і FULL перший виклик на рік — безкоштовно.
  • → Декларація ПНО / план ПЛАС — для потенційно небезпечних об'єктів (хімія, вибухонебезпечні, великі склади ЛЗР). Індивідуальна ціна, зазвичай 45 000-150 000 ₴. Включено у пакет цивільного захисту FULL.
  • → Психосоціальна оцінка команди (окремо, з психологом) — від 25 000 ₴. Типово як частина комплексного тренінгу вигорання/стресу.
  • → Експертиза документів з грифом «для службового користування» — індивідуально для MilTech і держ-сегменту.
FAQ

Часті запитання щодо тарифів

Чому SMART — anchor (рекомендуємо)?

80% клієнтів 30-100 осіб обирають саме SMART. Це оптимальний баланс: включена пожежна безпека (economía ~13 тис. ₴/міс vs роздільно), виїзди інженера, квартальний аудит, компенсація штрафу до 50 тис. ₴. У STARTі немає виїздів, у FULL — надмірний для середнього бізнесу.

Чи можна знизити або підвищити тариф під час договору?

Так, у будь-який момент. Зміна з наступного календарного місяця. Без штрафу за downgrade. Upgrade — ефект одразу (доплачується різниця за поточний місяць пропорційно).

Чи включено ПДВ у ціни?

Ціни вказані без ПДВ. Для ФОП — працюємо без ПДВ (3% єдиного податку). Для ТОВ з ПДВ — +20% до вказаних цін.

Що таке SLA і як він фіксується?

SLA — гарантований час відповіді та реакції. Прописаний окремим пунктом у договорі з конкретними годинами й компенсаціями. У START — 1 робочий день, SMART — 4 години, FULL — 1 година цілодобово.

Що не входить у тарифи (коротко)?

Разове розслідування НВ (від 15 тис.), судове представництво (від 25 тис.), нічні виклики (+50%), декларація ПНО (45-150 тис.). Детальніше — блок «Що не входить» вище.

Чи можна договір на 3 роки з фіксацією ціни?

Так, для клієнтів FULL або комплексного ENTERPRISE-пакета. Знижка 8% на другий рік, 12% на третій. Детальні умови — у вашому договорі.

Як розраховується «кількість осіб» для тарифу?

Бере до уваги всіх працівників за трудовими договорами + цивільно-правовими договорами з регулярним виконанням робіт. ФОПи-підрядники (дизайн, маркетинг) — не рахуємо, якщо не присутні на об'єкті.

Чи можна оплатити чеком або криптовалютою?

Стандартно — банківський переказ на рахунок ТОВ. Для міжнародних клієнтів — SWIFT/SEPA, USDT/USDC (tax-compliant). Готівка — ні.

Індивідуальний прорахунок під ваш бізнес — за 1 робочий день.
